# Handball Tactic Board (手球動態戰術板)

這是一個專為手球教練與球員設計的**互動式網頁戰術板**。支援跨平台（手機、平板、電腦）使用，讓您可以輕鬆演練陣地戰、繪製戰術路線，並將跑位過程直接錄製成影片或存檔分享！

## ✨ 核心功能介紹 (Features)

### 1. 智慧視角切換 (Smart View)
* **全場 / 半場無縫切換**：點擊左上角的 `Half Court`，畫面會自動旋轉 90 度並完美滿版縮放，符合直向手機或電腦的閱讀視角。
* **一鍵陣地戰佈陣**：首次切換到半場時，防守方（紅隊）會自動退防至 6 公尺線組成標準 6-0 防線；進攻方（藍隊）會從對面半場壓境，且進攻中鋒 (Pivot) 會自動切入卡位，中堅 (CB) 則會自動取得球權！

### 2. 自由拖曳與繪圖 (Drag & Draw)
* **直覺拖曳**：場上所有球員與球皆可自由使用滑鼠或手指拖曳，系統具備自動座標反算，即使場地旋轉也能精確跟隨手指。
* **戰術畫筆**：點擊 `Pen: OFF` 切換為 `Pen: ON` 開啟畫筆模式，可以直接在場地上畫出黃色的戰術路線。點擊 `Clear Pen` 即可一鍵清除。
* *備註：守門員 (7號) 特別標有黑色外框與數字以便快速識別。*

### 3. 動畫錄製與播放 (Animation Timeline)
您可以像拍定格動畫一樣製作流暢的戰術跑位：
1. 將球員擺放到起始位置。
2. 點擊下方的 **`Save Frame`** 記錄當前位置。
3. 移動球員到下一個位置，再次點擊 **`Save Frame`**。
4. 重複上述動作排好戰術後，點擊 **`Play Animation`**，系統就會用平滑的過渡動畫重現整個跑位過程！

### 4. 戰術匯出與讀取 (Export & Import)
* 🔴 **Record Video (錄製影片)**：
  設計好跑位後點擊此按鈕，瀏覽器會詢問您是否分享畫面。請選擇「分享目前的分頁」，系統就會**自動在背景側錄整個跑位動畫**，並在播完後自動下載一個 `.webm` 影片檔，讓您可以直接傳到 LINE 群組督促球員死背跑位。
* 🟦 **Save Play (儲存戰術檔)**：
  如果您想保留這個戰術未來繼續用，點擊此按鈕會跳出另存新檔視窗，將目前的所有跑位與陣型打包成一個極小的 `.json` 戰術專案檔。
* 🟦 **Load Play (讀取戰術檔)**：
  不論何時重新打開這個網頁，只要點擊此按鈕上傳您之前存的 `.json` 檔，系統會立刻完美復活當時的所有球員與跑位紀錄，讓您可以接續修改！

## 🚀 如何執行 (How to Run)

這是一個輕量級的純前端 Web 應用程式 (HTML/CSS/JS)，無需複雜安裝。
請在專案資料夾底下，開啟終端機並透過任意本地伺服器啟動：

**方法 A：使用 Python (推薦，通常 Mac/Windows 已內建)**
```bash
python -m http.server 8000
```
**方法 B：使用 Node.js**
```bash
npx serve .
```

啟動伺服器後，打開瀏覽器並前往 `http://localhost:8000` 即可開始使用您的戰術板！
